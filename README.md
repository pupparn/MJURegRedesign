# reg.mju.ac.th Redesign (Educational Project)

Redesign concept for Maejo University's registration system (reg.mju.ac.th), built for **educational purposes only** — a UI/UX practice project, not affiliated with or endorsed by Maejo University.

## ⚠️ Disclaimer

- Not an official Maejo University product.
- Not for production use, deployment to real students, or handling real data.
- No login/auth, no backend, no real student data involved.
- Static mockup only, meant for learning HTML/CSS/frontend design.

## Contents

- `index.html` — homepage / landing mockup
- `courses.html` — course listing page mockup
- `class-schedule.html` — class schedule page mockup
- `maejo.css` — shared stylesheet

## Usage

Open any `.html` file directly in a browser. No build step, no dependencies.
